# 学习与测试协议

## 首次作答

先让学习者完整回忆，不给首字母、选项或答案片段。按首次作答记录：

- `Again`：错误、空白、无法回忆，或核心含义不对。
- `Hard`：答案正确但依赖提示、明显犹豫，或遗漏非核心细节。
- `Good`：独立且正确。
- `Easy`：独立、迅速，并明确表示太简单。

判断开放题时允许语义等价，但不能把含糊、循环解释或只说上位概念判为正确。

## 错题补救

首次错误后立即：

1. 用一两句话说明正确答案和错因。
2. 换一种表述测试同一知识点，不得原题复读。
3. 补救仍错时继续换问法，直至答对一次或管理器返回补救上限。
4. 每次都用 `--remediation` 写入；补救不再次更新 FSRS，也不覆盖首次错误。
5. 达到单知识点或整场硬上限时，展示正确答案、保留未掌握状态并进入下一题，禁止继续循环。

变式优先级：

- `term`：正向释义 → 反向拼写 → 简短语境填空。
- `concept`：定义 → 特征辨析 → 因果/应用。
- `qa`：改写问句 → 反例辨析 → 应用情景。
- `cloze`：换语境或换缺口。
- `problem`：更换数字但保持同一解法；核对关键步骤。
- `procedure`：缺失步骤 → 排序 → 错误定位。

## 日常复习

顺序为逾期、预计记忆率低、当天到期。一次约 20 分钟。时间到后完成正在进行的错题补救，
再结束会话；未出题内容保持原到期日。

## 周测与月测

周测约 12 题/15 分钟，月测约 30 题/30 分钟。跨学科抽题时优先薄弱和久未测试条目，
同时避免同一主题连续堆叠。成绩只看每题首次回答；补救结果另列。
